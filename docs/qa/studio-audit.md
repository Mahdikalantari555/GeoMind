# ممیزی تجربهٔ کاربری GeoMind Studio

**دامنه:** اجرای مرورگر واقعی، با build دمو و بدون ترافیک خارجی. عکس‌ها در `docs/qa/studio/` هستند. هر هفت صفحه باز شد؛ در Acquire جست‌وجوی مصنوعی اجرا شد و در Settings فهرست ساختگی مدل‌ها دریافت، یک مدل تیک زده و بدنهٔ درخواست فعال‌سازی بررسی شد. باز شدن یک صفحه معادل تست همهٔ دکمه‌های آن نیست. تست مستقیم روتر پایتون مستقل از مرورگر است؛ تست سرتاسری با gateway کامل، دانلود STAC، هزینه/مجوز استنتاج و آموزش واقعی **انجام نشده‌اند**.

**مسیر خوانده‌شده:** `SettingsView → store.updateSettings` پیش از تغییر فقط state محلی را عوض می‌کرد. `routers/models.py` انبار embedding را می‌خواند. `routers/workspace.py` تنظیمات واقعی، قفل نوشتن و راه‌اندازی مجدد agent را مدیریت می‌کند. `qa/backend_factory.py` برای API کلید محیطی را می‌خواند و در حالت offline درخواست را نمی‌پذیرد. بنابراین برای فهرست مدل چت، مسیر جداگانه‌ای لازم بود، نه استفادهٔ مجدد از فهرست embedding.

## بازتولید شواهد

```sh
(cd apps/studio && pnpm install --frozen-lockfile && pnpm check && pnpm test && VITE_GEOMIND_DEMO=1 pnpm build)
npm install --prefix /tmp/qa puppeteer-core@24 @sparticuz/chromium@141
NODE_PATH=/tmp/qa/node_modules node scripts/qa/studio-smoke.cjs
# in the configured Python env
pytest server/tests/test_provider_discovery.py -q
```

نیاز مرورگر: Chromium لینوکس و کتابخانه‌های NSS/NSPR. در این sandbox کتابخانه‌های همراه بستهٔ Chromium از `al2023.tar.br` در `/tmp/al` استخراج و `LD_LIBRARY_PATH=/tmp/al/lib` تنظیم شد. برای تکرار با حساب واقعی: ابتدا workspace آزمایشی باز و offline خاموش شود، کلید مختص ارائه‌دهنده روی gateway تنظیم شود؛ یک مدل را فعال کنید، workspace را مجدد باز کنید و با اجازهٔ کاربر یک سؤال غیرحساس بپرسید. کلید، header و متن خصوصی در گزارش یا عکس ثبت نشود.

**به‌روزرسانی پس از ممیزی:** ردیف‌های ۴ تا ۲۸ در پنج گروه متوالی پیاده‌سازی شدند؛ معیارهای جاری در `openspec/specs/web-app/spec.md` ثبت شده‌اند. اتصال سفارشی نیازمند تأیید آدرس توسط مدیر gateway است. تصاویر بالا شواهد اجرای اولیه هستند، نه تأیید تعامل‌به‌تعامل نسخهٔ جدید.
